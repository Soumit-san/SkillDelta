# 🚀 Running SkillDelta in VS Code

SkillDelta is built with **Vite** and **React**. To run it on your machine, follow these simple steps:

### 1. Prerequisites
- **Node.js**: Make sure you have it installed. Download it here: [nodejs.org](https://nodejs.org/).

### 2. Open Project
1. Open **VS Code**.
2. Go to `File > Open Folder...` and select `sidereal-hubble`.

### 3. Open Terminal
Press ``Ctrl + ` `` to open the terminal in VS Code.

### 4. Install Dependencies
Run the command below in your terminal to install the necessary packages (like Lucide and Recharts):
```bash
npm install
```

### 5. Start the App
Start the development server with:
```bash
npm run dev
```

### 6. Access the App
Look for the local URL in your terminal (typically `http://localhost:5173/`).
- Hold `Ctrl` and click the link to open it.
- Log in to see **Tanishq's** personalized dashboard!

---
**💡 Tip**: If you want to build the production-ready version later, you can use `npm run build`.
